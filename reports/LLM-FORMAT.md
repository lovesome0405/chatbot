# 생성 출력 형식 실험 (2026-11-17, Ollama 0.12.6, CPU 4코어)

같은 근거 2개(장학표 행 2·3)와 질문 3개로 비교했다(관찰 기록이며 통계 실험 아님).

| 설정 | "학과수석 입학자는 장학금 얼마나 받아?" | 영어 같은 질문 | 근거 없는 "기숙사 신청은 언제야?" |
|---|---|---|---|
| qwen2.5:3b + `format`=JSON schema(abstain 필드 먼저) | `{"abstain": true, "claims": []}` | 동일 | 동일 |
| qwen2.5:3b + JSON schema(claims 먼저 / claims만) | `{"claims": []}` | 동일 | 동일 |
| qwen2.5:3b + `format:"json"` + 예시 1개 프롬프트 | 답변 생성. 단 발췌가 `구분 \| 종류 \| 지급액` 식으로 중간 구절을 건너뜀 | `{"claims": []}` | `{"claims": []}` (올바른 보류) |

조치
1. 기본값을 `OLLAMA_FORMAT=json` + 예시 프롬프트로 바꿨다. schema 모드는 설정으로 남겼다.
2. 근거가 한국어일 수 있다는 문장, 기준일(Asia/Seoul), 기간 비교 지시를 프롬프트에 넣었다.
3. 서버 인용 검증에 구절 규칙을 명시했다. ` | `나 `…`로 이은 발췌는 각 구절이 원문에 **순서대로** 그대로 있어야 통과한다. 순서가 바뀌거나 단어가 바뀌면 버린다(단위 테스트 있음).

qwen2.5:7b 비교(질문 3개만, 전체 평가 아님): 한국어 장학 질문은 "1년간 교육비 전액면제"로 정확했다. 영어 질문 "How much tuition is waived for a student with top grades in the previous semester?"에는 **다른 행(이사장 장학금, 2년간)**을 인용했다. 발췌가 원문 그대로라 자동 검증을 통과한 의미 오류다. 기간 질문은 보류했다. 응답은 약 50~95초 걸렸다. 이 결과 때문에 인용의 의미 일치는 사람 검토나 정답셋으로 따로 봐야 한다.
