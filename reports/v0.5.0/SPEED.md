## 5. 미리 만든 답(B)의 사람 검토 관문

[실생성] qwen3:4b로 39개(아리 37·롤리폴리 2, 시간 상한 없음, 약 13분)를 만들었다. 내 1차 확인에서 근거 범위를 넘는 의심 답(운현궁 코스 설명, "영어 지원" 과장, 일부만 나열한 장학 목록)이 나와, **사람이 '맞음'으로 판정한 답만 화면에 내보내도록** 바꿨다(`RAG_CACHE_REQUIRE_REVIEW=1` 기본).

```bash
python -m ragcore.cli cache-export --out warm-review.csv   # 판정 열에 맞음/틀림/애매
python -m ragcore.cli cache-import --csv warm-review.csv   # 맞음 → 사용, 틀림 → 다시 만들지 않음
```
자료 버전이 바뀌면 판정도 무효가 된다(새로 만들고 다시 검토). 현재 판정은 **비어 있다** → 지금은 모든 질문이 실시간 경로(10초 이내)로 답한다. 내 메모: `reports/v0.5.0/warm-review.csv`.
