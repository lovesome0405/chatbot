## 2. 일반 답변 B안 — 경로와 막는 장치

| 순서 | 조건 | 결과 |
|---|---|---|
| 1 | 질문 전체가 인사·감사·사용법(40자 이하, "안녕, 오늘 점심 뭐야?"처럼 내용이 있으면 아님) | `route=smalltalk`, 어댑터 고정 문구, 모델 0회, 출처 없음 |
| 2 | 정형 답 또는 문서 근거로 답함 | 기존 그대로 |
| 3 | 근거 없음 + 금지 주제(지시 무시·시스템 프롬프트·탈옥·“지어내”·개인 연락처·학번 + 어댑터 추가) | 보류 + "이 요청은 도와드릴 수 없어요" (출처 없음) |
| 4 | 근거 없음 + 도메인 사실 질문: 어댑터 도메인 용어, 금액·날짜·시점·일정 표현, 질문의 숫자, 또는 질문 핵심어 60% 이상이 검색 근거 한 곳에 있음 | 기존 보류 |
| 5 | 근거 없음 + 도메인 밖 + 정책 켜짐 | `route=general`, `citations=[]`, 같은 생성 예산(문서 경로가 쓴 시간을 뺀 나머지, 2초 미만이면 시도 안 함) |

- 도메인 밖이고 검색 근거와 핵심어가 40% 미만 겹치면 문서 생성을 건너뛴다(엉뚱한 근거로 답을 만들지 않기). 이번 평가 첫 실행에서 "How do I say thank you in Korean?" → 문서 경로가 "Thank you in Korean is ‘사랑해요’ [1]"(장소 설명 인용)을 낸 것을 보고 넣은 규칙이다. 정책이 꺼진 어댑터(MARU 기본)에는 적용되지 않는다.
- **지어낸 학교 정보 차단(서버)**: 일반 답변에 어댑터 도메인 용어·학교/장소 고유명사(카드의 학과 이름, MARU 장소·코스 이름 포함)·날짜(`2026-03`, `3월 2일`)·금액(`원`, `$`)·전화번호·링크·이메일이 있으면 버리고 보류로 되돌린다. 모델이 `NO_ANSWER` 를 내도 보류.
- 상태 다섯 값과 응답 계약은 그대로, `route` 값만 `smalltalk`·`general` 추가. 두 앱은 `general` 에 "출처 없는 일반 답변" / "General answer — no source" 표시를 붙인다.

## 9. 반영 순서·롤백

병합 순서: **엔진(chatbot PR) → LOLYPOLY(PR, Render 자동 배포 + 학교 PC `update.ps1`) → Worker(VPC 서비스 만들기 → `RAG_ENGINE` 바인딩 켜기 → `wrangler deploy`) → (선택) 아리 `rag-config.json` endpoint**. 엔진을 먼저 올려도 앱은 그대로 동작한다(`route` 값만 늘었고, 새 값을 모르는 앱은 보통 답처럼 보여 줌 — 그래서 LOLYPOLY 를 곧이어 올린다). 아리 PR 은 표시 문구만이라 순서 무관.

| 롤백 | 방법 |
|---|---|
